# 🏠 AI Real Estate Bot - Полное решение для недвижимости

Комплексная система AI-бота для работы с клиентами через WhatsApp и веб-сайт, с автоматической генерацией контента и интеграцией с n8n для полной автоматизации бизнес-процессов.

## 🚀 Возможности

### 1. **AI-Ассистент для клиентов**
- ✅ Интеллектуальное общение через WhatsApp, веб-сайт и Telegram
- ✅ Автоматическое уточнение параметров недвижимости
- ✅ Умный подбор объектов по предпочтениям
- ✅ Персонализированные рекомендации
- ✅ Организация просмотров

### 2. **Интеграция с WhatsApp Business**
- ✅ Прием и отправка сообщений через Twilio API
- ✅ Массовые рассылки
- ✅ Автоматические уведомления клиентам
- ✅ Отправка фото объектов

### 3. **Веб-виджет для сайта**
- ✅ Современный красивый интерфейс чата
- ✅ Адаптивный дизайн (мобильные и десктоп)
- ✅ Typing indicators

- ✅ Каталог объектов недвижимости

### 5. **Генератор контента для соцсетей**

- ✅ Посты с отзывами клиентов

- ✅ REST API для всех операций

## 🛠 Установка и настройка

### 1. Установите зависимости

```bash
pip install -r requirements.txt
```

### 2. Настройте переменные окружения

Создайте файл `.env`:

```bash
# OpenAI API
OPENAI_API_KEY=your_openai_api_key

# Telegram (опционально)
TELEGRAM_BOT_TOKEN=your_telegram_token

# Twilio для WhatsApp
TWILIO_ACCOUNT_SID=your_twilio_sid
TWILIO_AUTH_TOKEN=your_twilio_auth_token
TWILIO_WHATSAPP_NUMBER=whatsapp:+14155238886
```

### 3. Запустите главный сервер

```bash
python api_server.py
```

Сервер запустится на `http://localhost:5000`

### 4. (Опционально) Запустите WhatsApp бот

```bash
python whatsapp_bot.py
```

WhatsApp webhook будет доступен на `http://localhost:5001/whatsapp/webhook`

## 🌐 API Endpoints

### Чат с AI-ассистентом
```bash
POST /api/chat
{
  "client_id": "unique_client_id",
  "message": "Ищу квартиру в центре до 5 млн",
  "channel": "website"
}
```

### MCP команды для n8n
```bash
POST /api/mcp
{
  "action": "create_client",
  "params": {
    "name": "Иван Петров",
    "phone": "+79991234567",
    "channel": "whatsapp"
  }
}
```

### Управление объектами
```bash
# Получить объекты
GET /api/properties?type=apartment&min_price=3000000&max_price=5000000

# Добавить объект
POST /api/properties
{
  "title": "2-комнатная квартира в центре",
  "type": "apartment",
  "price": 4500000,
  "location": "Москва, Центральный район",
  "area": 65,
  "rooms": 2,
  "description": "Отличная квартира с ремонтом",
  "images": ["url1.jpg", "url2.jpg"]
}
```

### Генерация контента
```bash
# Сгенерировать один пост
POST /api/content/generate
{
  "type": "post",
  "template": "property_showcase",
  "properties": [{ "title": "...", "price": 5000000, ... }]
}

# Создать контент-пакет на месяц
POST /api/content/pack
{
  "posts": 10,
  "stories": 15
}
```

### Получить расписание контента
```bash
GET /api/content/schedule?limit=30
```

## 🔗 Интеграция с n8n

### Доступные MCP действия:

1. **create_client** - Создать клиента
2. **update_preferences** - Обновить предпочтения
3. **get_client** - Получить данные клиента
4. **add_property** - Добавить объект
5. **search_properties** - Поиск объектов
6. **create_content** - Создать контент
7. **get_content_schedule** - Расписание контента

### Готовые Workflows (в файле n8n_workflows.json):

1. **Обработка новых лидов** - Автоматически создает клиента и отправляет приветствие
2. **Автоматический подбор объектов** - Ищет и отправляет подходящие варианты
3. **Публикация контента по расписанию** - Автопостинг в соцсети
4. **Обработка входящих WhatsApp** - AI обрабатывает все сообщения
5. **Генерация контент-пакета** - Автоматически создает контент на месяц
6. **Уведомления о горячих лидах** - Алертит менеджеров

### Настройка n8n:

1. Импортируйте workflows из `n8n_workflows.json`
2. Настройте URL вашего сервера в HTTP Request нодах
3. Добавьте credentials для WhatsApp, Telegram, Instagram
4. Активируйте workflows

## 🎨 Веб-виджет для сайта

### Интеграция на ваш сайт:

```html
<!-- Вставьте в конец <body> вашего сайта -->
<script>
  (function() {
    const script = document.createElement('script');
    script.src = 'http://your-domain.com/widget';
    document.body.appendChild(script);
  })();
</script>
```

Или просто скопируйте содержимое `web_widget.html` на вашу страницу.

### Кастомизация виджета:

В файле `web_widget.html` вы можете изменить:
- Цвета (градиенты в CSS)
- Положение кнопки
- Тексты приветствия
- Размеры окна

## 📱 WhatsApp интеграция

### Настройка Twilio:

1. Зарегистрируйтесь на [Twilio](https://www.twilio.com/)
2. Получите WhatsApp sandbox или настройте WhatsApp Business API
3. Настройте webhook: `https://your-domain.com/whatsapp/webhook`
4. Добавьте credentials в `.env`

### Доступные эндпоинты:

- `POST /whatsapp/webhook` - Прием сообщений от WhatsApp
- `POST /whatsapp/send` - Отправка сообщения одному клиенту
- `POST /whatsapp/broadcast` - Массовая рассылка

## 📊 Генератор контента

### Типы контента:

1. **property_showcase** - Презентация одного объекта
2. **selection** - Подборка объектов (ТОП-5, под бюджет и т.д.)
3. **tips** - Полезные советы по недвижимости
4. **success_story** - История успешной сделки
5. **review_post** - Пост с отзывом клиента

### Пример генерации контента:

```python
from content_generator import content_generator

# Создать пост об объекте
post_text = content_generator.generate_post_text(
    template_type="property_showcase",
    properties=[property_data]
)

# Создать контент-пакет на месяц
pack = content_generator.create_content_pack(
    num_posts=10,
    num_stories=15
)
# Вернет: {"posts": [...], "stories": [...], "schedule": [...]}
```

## 🗄️ База данных

Система использует SQLite для хранения:

- **Клиенты** - данные, предпочтения, история
- **Объекты** - каталог недвижимости
- **Контент** - сгенерированные посты и расписание

База автоматически создается при первом запуске в `data/crm.db`
