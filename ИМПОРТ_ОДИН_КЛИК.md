# 🚀 Импорт ВСЕХ workflows ОДНИМ КЛИКОМ

## ✅ Готов файл: `n8n_ALL_WORKFLOWS.json`

Этот файл содержит **ВСЕ 6 workflows** и импортируется **за один раз**!

---

## 📥 Инструкция (3 простых шага)

### Шаг 1: Откройте n8n
```bash
n8n start
```
Откройте в браузере: **http://localhost:5678**

### Шаг 2: Импортируйте файл

**В n8n:**

1. Нажмите **"Workflows"** (слева в меню)

2. Нажмите **"..."** (три точки справа вверху)

3. Выберите **"Import from File"**

4. Выберите файл: **`n8n_ALL_WORKFLOWS.json`**

5. Нажмите **"Open"**

6. ✅ **ВСЕ 6 workflows импортированы!**

### Шаг 3: Активируйте workflows

**Для каждого workflow:**

1. Откройте workflow из списка
2. Нажмите переключатель **"Inactive" → "Active"** (справа вверху)
3. Workflow станет зеленым ✅

**Повторите для всех 6:**
- ✅ 1️⃣ Новый лид - Автоматическая обработка
- ✅ 2️⃣ Автоподбор объектов по предпочтениям
- ✅ 3️⃣ Публикация контента по расписанию
- ✅ 4️⃣ WhatsApp - AI обработка сообщений
- ✅ 5️⃣ Генерация контент-пакета на месяц
- ✅ 6️⃣ Уведомления о горячих лидах

## ⚙️ Настройка (ВАЖНО!)

### 1. Запустите API сервер

**В отдельном терминале:**
```bash
cd /workspace

# Установите зависимости (первый раз)
pip install -r requirements.txt

# Создайте .env с вашим ключом
echo "OPENAI_API_KEY=sk-ваш-ключ" > .env

# Запустите сервер
python api_server.py
```

### 2. Проверьте URL в workflows

**Если API на localhost:5000** - ничего менять не нужно ✅

**Если API на другом адресе:**
- Откройте каждый workflow
- Кликните на ноды "HTTP Request"
- Замените `http://localhost:5000` на ваш URL
- Сохраните

### 3. Добавьте переменные (для Telegram)

**В n8n:**
- Settings (шестеренка слева) → Variables
- Добавьте:
  - `TELEGRAM_BOT_TOKEN` = ваш_токен
  - `TELEGRAM_MANAGER_CHAT_ID` = ваш_chat_id

## 🧪 Тестирование

### Тест 1: Проверка API
```bash
curl http://localhost:5000
```
Должен вернуть: `{"status": "online", ...}`

### Тест 2: Добавить тестовый объект
```bash
curl -X POST http://localhost:5000/api/properties \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Тестовая квартира",
    "type": "apartment",
    "price": 5000000,
    "location": "Москва",
    "area": 60,
    "rooms": 2,
    "description": "Отличная квартира"
  }'
```

### Тест 3: Создать лида через n8n
```bash
curl -X POST http://localhost:5678/webhook/new-lead \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Тест Тестов",
    "phone": "+79999999999",
    "channel": "test",
    "preferences": {"type": "apartment"}
  }'
```

**Ожидаемый результат:**
```json
{
  "success": true,
  "client_id": "client_...",
  "message": "Лид создан, приветствие отправлено"
}
```

### Тест 4: Проверка в n8n

1. Откройте **Executions** (слева в меню)
2. Выберите workflow "1️⃣ Новый лид"
3. Должно быть зеленое выполнение ✅
