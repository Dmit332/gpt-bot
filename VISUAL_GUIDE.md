### 6. Настройка HTTP Request нода

Кликните на нод "Создать клиента":

```
┌─────────────────────────────────────────────────┐
│  HTTP Request                               [x] │
├─────────────────────────────────────────────────┤
│                                                  │
│  Method:  [POST ▼]                              │
│                                                  │
│  URL:     http://localhost:5000/api/mcp         │
│           ↑ ПРОВЕРЬТЕ/ИЗМЕНИТЕ                  │
│                                                  │
│  Authentication: [None ▼]                       │
│                                                  │
│  Body Content Type: [JSON ▼]                    │
│                                                  │
│  JSON Body:                                      │
│  {                                              │
│    "action": "create_client",                   │
│    "params": {...}                              │
│  }                                              │
│                                                  │
│                              [Cancel] [Execute] │
└─────────────────────────────────────────────────┘
```

**Что проверить:** 
- URL должен быть `http://localhost:5000` (если локально)
- Или `http://your-domain.com` (если на сервере)

## 🎯 Пошаговый чек-лист с визуализацией

### ☑️ Шаг 1: Открыть n8n
```
Терминал → n8n start → Браузер: localhost:5678
```

### ☑️ Шаг 2: Создать новый workflow
```
Нажать [+] → Нажать [...] → Import from File
```

### ☑️ Шаг 3: Выбрать файл
```
n8n_workflow_1_new_lead.json → Open
```

### ☑️ Шаг 4: Сохранить
```
Нажать [Save]
```

### ☑️ Шаг 5: Проверить URL
```
Кликнуть "HTTP Request" → Проверить URL → localhost:5000
```

### ☑️ Шаг 6: Активировать
```
Нажать [Inactive] → Станет [Active] зеленым
```

### ☑️ Шаг 7: Скопировать webhook
```
Кликнуть "Webhook" → Скопировать Production URL
```

### ☑️ Шаг 8: Повторить для всех 6
```
Импорт → Сохранить → Проверить → Активировать
```

### ☑️ Шаг 9: Протестировать
```
Терминал → curl -X POST ... → Проверить ответ
```

### ☑️ Шаг 10: Проверить Executions
```
n8n → Executions → Должны быть зеленые ✅
```
