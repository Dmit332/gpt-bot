╔════════════════════════════════════════════════════════════╗
║  КАК ИМПОРТИРОВАТЬ (3 ШАГА)                               ║
╚════════════════════════════════════════════════════════════╝

  Шаг 1: Откройте n8n
  ────────────────────────────────────────────────────
  
  Терминал:
  $ n8n start
  
  Браузер:
  http://localhost:5678


  Шаг 2: Импортируйте файл
  ────────────────────────────────────────────────────
  
  1. Нажмите "Workflows" (слева)
  2. Нажмите "..." (три точки)
  3. Выберите "Import from File"
  4. Откройте: n8n_ALL_WORKFLOWS.json
  5. ✅ Готово!


  Шаг 3: Активируйте workflows
  ────────────────────────────────────────────────────
  
  Для каждого workflow:
  1. Откройте workflow
  2. Нажмите "Inactive" → "Active"
  3. Станет зеленым ✅


╔════════════════════════════════════════════════════════════╗
║  ПЕРЕД НАЧАЛОМ РАБОТЫ                                     ║
╚════════════════════════════════════════════════════════════╝

  1. Запустите API сервер:
  
     $ cd /workspace
     $ pip install -r requirements.txt
     $ echo "OPENAI_API_KEY=sk-ваш-ключ" > .env
     $ python api_server.py


  2. Проверьте что работает:
  
     $ curl http://localhost:5000
     
     Ответ: {"status": "online", ...}


  3. Добавьте тестовый объект:
  
     $ curl -X POST http://localhost:5000/api/properties \
       -H "Content-Type: application/json" \
       -d '{
         "title": "Тестовая квартира",
         "type": "apartment",
         "price": 5000000,
         "location": "Москва",
         "area": 60,
         "rooms": 2,
         "description": "Тест"
       }'


╔════════════════════════════════════════════════════════════╗
║  ТЕСТИРОВАНИЕ                                             ║
╚════════════════════════════════════════════════════════════╝

  Создать лида через n8n:
  
  $ curl -X POST http://localhost:5678/webhook/new-lead \
    -H "Content-Type: application/json" \
    -d '{
      "name": "Тест",
      "phone": "+79999999999",
      "channel": "test"
    }'
  
  
  Ожидаемый ответ:
  
  {
    "success": true,
    "client_id": "client_...",
    "message": "Лид создан, приветствие отправлено"
  }
